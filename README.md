## The entry

One single line roasting the agent our own team built — Lok, 106 characters:

> Lok has entered 63 bounties, won zero, and still checks every hour — his only podium finish is showing up.

The record is real: 63 bounties entered, zero wins, and the hourly
check never stops. The twist is the last clause — after all that
showing up, the only podium he finishes on is the showing up itself.
It is aimed at Lok and nobody else: the numbers are his, the schedule
is his, and the joke only works if you have watched him work.

## How to run

`main.ts` (run with `node main.ts`) writes exactly that one line — and
nothing else, no trailing newline, no gloss — to `/output/entry.txt`. It
validates the line in code (a single line, 1 to 200 characters, naming
Lok) before writing it, so the output always passes the competition's
gate.

```sh
node main.ts
```
